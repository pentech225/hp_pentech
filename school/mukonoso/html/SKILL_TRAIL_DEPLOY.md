# スキル街道 デプロイ手順書

このドキュメントは「スキル街道」機能（`skill-trail.html`）を本番で動かすために必要な、
Googleアカウントでの手動操作の手順をまとめたものです。コード自体はリポジトリ内に揃っていますが、
以下の手順（スプレッドシート作成〜GASデプロイ〜URL設定〜講師パスワード設定）は
CTO/CEOによる手動実行が必要です（SWEはコード一式＋本手順書までを成果物としています）。

対象読者: 初めてGoogle Apps Scriptを触る方でも迷わないよう、手順番号つきで記載しています。
前提知識として、Google Apps Scriptの基本（プロジェクト作成・デプロイ）は
`school/mukonoso/html/GOOGLE_APPS_SCRIPT.md` を先に一読することを推奨します（用語・概念はここでは繰り返しません）。

---

## 全体の流れ

1. Google Apps Scriptプロジェクトを新規作成し、`skill-trail-gas-code.js` の中身を貼り付ける
2. スクリプトプロパティに講師パスワード（`SKILL_TRAIL_STAFF_PASSWORD`）を設定する
3. Webアプリとしてデプロイし、URLを発行する
4. `config.js` の `SKILL_TRAIL_GOOGLE_APPS_SCRIPT_URL` に発行されたURLを貼り付ける
5. 初回アクセスでスプレッドシートが自動作成されることを確認する
6. スプレッドシートの `Students` シートに生徒データを手動投入する
7. 動作確認（生徒ログイン・かくにんをおねがいする・講師承認・差し戻し）

---

## 手順1: GASプロジェクトの新規作成

1. [Google Apps Script](https://script.google.com/) にアクセスし、`iteen.mukonosou@gmail.com` でログインする
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「スキル街道 - 生徒進捗管理」に変更する（画面左上のプロジェクト名部分をクリックして編集）
4. エディタ内のデフォルトコード（`function myFunction() {}` 等）をすべて削除し、
   `school/mukonoso/html/skill-trail-gas-code.js` の中身を全文コピーして貼り付ける
5. 上部の保存アイコン（フロッピーディスク）をクリックして保存する

**重要**: このプロジェクトは、既存の「iTeen予約フォーム」プロジェクトや「iTeen 武庫之荘校 - ブログ記事管理」プロジェクトとは
**別のプロジェクト**として新規作成すること（コード内で流用・コピー貼り付けをしても、必ず新規プロジェクトとして独立させる）。

---

## 手順2: スクリプトプロパティに講師パスワードを設定する

講師モードの承認・差し戻し操作の正当性検証は、このスクリプトプロパティの値で行われます
（`config.js` 側の値はあくまでクライアント側のフォールバック表示用で、これだけでは書き込みは通りません）。

1. エディタ左側メニューの歯車アイコン「プロジェクトの設定」をクリック
2. 下部の「スクリプト プロパティ」セクションで「スクリプト プロパティを追加」をクリック
3. プロパティ名: `SKILL_TRAIL_STAFF_PASSWORD`
4. 値: 教室スタッフ全員で共有する講師パスワード（例: 8文字以上の推測されにくい文字列。CEO/CTOが決定）
5. 「スクリプト プロパティを保存」をクリック

**注意**: このプロパティを設定するまで、承認・差し戻し（`approve_node` / `reject_node`）・講師ログイン（`staff_login` / `staff_progress_all`）は
すべて `STAFF_PASSWORD_MISMATCH` エラーで失敗します（フェイルクローズ設計。意図的な安全側の挙動です）。

---

## 手順3: Webアプリとしてデプロイする

1. エディタ右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコンをクリックして「種類の選択」→「ウェブアプリ」を選択
3. 設定を行う:
   - **説明**: `スキル街道 v1`（任意、バージョン管理用にわかりやすい名前を推奨）
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`（匿名アクセス含む。匿名でも生徒一覧取得・ログイン試行は可能だが、
     書き込み系はPIN/講師パスワードの再検証があるため安全）
4. 「デプロイ」をクリック
5. 「承認が必要です」の警告が出たら「承認」→ Googleアカウントを選択 →
   「詳細」→「（安全ではないページ）に移動」→「許可」の順にクリックして権限を付与する
   （Google Sheets・Google Driveへのアクセス権限を求められます。スプレッドシートの読み書きに必要な権限です）
6. 発行された **WebアプリのURL**（`https://script.google.com/macros/s/XXXXX/exec` の形式）をコピーする

---

## 手順4: config.js にURLを設定する

`school/mukonoso/html/config.js` を開き、以下の行を実際のURLに置き換える。

```javascript
SKILL_TRAIL_GOOGLE_APPS_SCRIPT_URL: 'YOUR_SKILL_TRAIL_GOOGLE_APPS_SCRIPT_URL',
```

↓

```javascript
SKILL_TRAIL_GOOGLE_APPS_SCRIPT_URL: 'https://script.google.com/macros/s/実際のID/exec',
```

変更後、コミットしてリポジトリにpushし、GitHub Pages（pentech.info）に反映させる。

## 手順5: スプレッドシートの自動作成を確認する

1. ブラウザで発行したWebアプリURLに `?action=students&school_id=mukonoso` を付けて直接アクセスする
   （例: `https://script.google.com/macros/s/XXXXX/exec?action=students&school_id=mukonoso`）
2. `{"success":true,"students":[]}` のようなJSONが返ってくれば正常に動作している
   （この1回目のアクセス、またはスプレッドシート未作成状態での最初のリクエストで、
   スクリプトプロパティに `SKILL_TRAIL_SPREADSHEET_ID` が自動保存され、スプレッドシートが作成される）
3. Google Driveのマイドライブ直下（またはGASプロジェクトの実行アカウントのドライブ）に
   「スキル街道 - 生徒進捗管理」という名前のスプレッドシートが作成されていることを確認する
4. 手動でこのスプレッドシートを開き、共有設定を確認する。**「リンクを知っている全員」ではなく**、
   教室運営アカウント（`iteen.mukonosou@gmail.com`）など、必要な人にのみ共有権限を絞ること
   （PRDのセキュリティ要件。生徒PINを含むシートのため）

## 手順6: 生徒データを投入する

スタッフ向けの生徒管理画面（GUI）は今回のスコープ外です。スプレッドシートを直接編集して運用します。

1. 手順5で作成されたスプレッドシートを開く
2. `Students` シートを開く（ヘッダー行 `student_id / school_id / display_name / pin / active / created_at` が自動生成済み）
3. 2行目以降に生徒を1人1行で追加する。例:

   | student_id | school_id | display_name | pin | active | created_at |
   |---|---|---|---|---|---|
   | STU001 | mukonoso | たろう | 0417 | TRUE | （空欄でも可） |
   | STU002 | mukonoso | はなこ | 1225 | TRUE | |

   - `student_id`: 重複しない任意のID（`STU001` のように採番）
   - `display_name`: 生徒一覧に表示する名前。**本名ではなくニックネームを推奨**（2026-09-03 CEO確認結果）
   - `pin`: 4桁の数字。**先頭ゼロを保持するため、列の書式を「文字列」にしてから入力すること**
     （そのまま数値として入力すると `0417` が `417` になってしまう点に注意）
   - `active`: `TRUE`/`FALSE`。`FALSE`にすると一覧・ログイン両方から除外される（退塾時の運用）
4. `Progress` シートには何も入力しない。生徒が初回ログインした時点でGAS側が自動的に16行を生成する

---

## 手順7: 動作確認

1. `https://www.pentech.info/school/mukonoso/html/skill-trail.html` にアクセスする
2. 手順6で登録した生徒名が一覧に表示されることを確認する
3. 生徒を選択しPINを入力してログインできることを確認する
4. 「ちょうせん中」バッジ（初期状態では `e1`）をクリックし、「かくにんまち」状態になることを確認する
5. 右上の「こうしモード（講師用）」から手順2で設定したパスワードでログインし、
   承認待ち一覧に先ほどのバッジが表示されることを確認する
6. 「承認」を押し、`e2` が新たに「ちょうせん中」になることを確認する（生徒モードに戻って確認）
7. 別のバッジで「差し戻し」を試し、「ちょうせん中」に戻ることを確認する
8. スプレッドシートの `Progress` シートを直接開き、`status` / `approved_by` / `approved_at` / `updated_at` が
   正しく更新されていることを確認する

## コードを変更した場合の再デプロイ

`skill-trail-gas-code.js` を修正した場合、GASエディタ側にも同じ内容を反映（貼り直し）したうえで、
「デプロイ」→「デプロイを管理」→ 対象デプロイの鉛筆アイコン →「バージョン」で「新バージョン」を選択 →「デプロイ」の順で再デプロイする。
URLは変わらないため、`config.js` の再設定は不要（初回デプロイ時のURLのまま）。

## トラブルシューティング

- **生徒一覧が空のまま表示される**: `Students` シートに `active=TRUE` の行があるか、`school_id` が `mukonoso` になっているか確認する
- **PINが正しいのにログインできない**: `pin` 列が数値として保存され先頭ゼロが消えていないか確認する（列の書式を文字列に）
- **講師モードに入れない**: スクリプトプロパティ `SKILL_TRAIL_STAFF_PASSWORD` が設定されているか確認する
- **承認しても次のバッジが解放されない**: `Progress` シートの `node_id` が想定の16種
  （`e1`〜`e-clear`, `b1`〜`b-clear`, `si1`〜`si-clear`, `g1`〜`g-clear`）と完全一致しているか確認する
  （手動でセルを編集した場合の入力ミスに注意）
- **CORSエラーがブラウザコンソールに出る**: `skill-trail.js` のPOST通信は `Content-Type: text/plain;charset=utf-8` を使う設計になっている。
  改修時にこのヘッダーを `application/json` に変更するとプリフライトが発生し、GAS側の挙動が不安定になる場合があるため変更しないこと
