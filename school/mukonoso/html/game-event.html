🎮 ゲーム大会

生徒たちが作成したScratchゲームで遊ぼう！

🎯 ゲーム大会とは

iTeen武庫之荘校では、定期的にゲーム大会を開催しています。このイベントでは、生徒たちが授業で作成したScratchゲームをみんなで遊ぶことができます。

プログラミングを学んだ成果を発表する場として、また、他の生徒の作品を見て刺激を受ける場として、多くの生徒が楽しみにしているイベントです。

✨ イベントの魅力

  • 生徒作品を実際にプレイ：授業で作成されたScratchゲームを実際に遊べます
  • みんなで楽しむ：友達や保護者の方と一緒に、ゲームを楽しむことができます
  • 作品へのフィードバック：ゲームを作った生徒に、感想やアドバイスを伝えることができます
  • プログラミングへの興味向上：他の生徒の作品を見ることで、「自分もこんなゲームを作りたい！」という気持ちが芽生えます
  • 交流の場：年齢や学校を越えて、同じ興味を持つ仲間と出会えます

🎮 武庫っ子あつまれ！ゲームプログラミング大会

プログラミングが初めてのお子さんも楽しめる体験イベント

🎯 イベント概要

プログラミングが初めての生徒児童にも分かりやすく、楽しくその仕組みや魅力を伝える啓蒙イベントです。Scratchゲームのプレイ（マウスやキーボード操作練習）という基本から、コードの改造を行うことで変数や各種プログラミング処理の意味を体感してもらいます。

さらに、基礎に習熟した子ども達向けには、より本格的なテーマ教材作品を元にして、短時間で楽しみながら密度の濃い学習を行えるように内容を整えています。

📚 プログラム内容

【ステップ1】ゲームをプレイしてみよう！（20分）

見本のゲームにそって、参加児童が自分だけのゲームづくりに挑戦！
想像力を膨らませて、様々なアルゴリズムで構築されたゲームをプレイします！

【ステップ2】ゲーム改造でもりあがろう！（20分）

完成したゲームに、もっとワクワクをプラス！
・キャラクターが画面の外へ飛び出す！？
・思わず「あっ！」と驚く仕掛けが盛りだくさん！

コーチのアドバイスで、作品をさらにパワーアップ！

✨ このイベントの魅力

  • 初心者でも安心：プログラミングが初めてのお子さんでも、楽しく参加できます
  • 実際にゲームを作る：見本を見ながら、自分だけのゲームを作成できます
  • 改造で学ぶ：完成したゲームを改造することで、プログラミングの仕組みを体感できます
  • コーチがサポート：経験豊富なコーチが丁寧に指導します
  • 短時間で集中学習：40分という短い時間で、密度の濃い学習ができます
