# iTeen武庫之荘校 コエテコ活用×尼崎/兵庫県No.1 販促戦略

**作成日**: 2026-08-20
**位置づけ**: 販促の核となる資料。ビジョン（尼崎No.1→兵庫県No.1）とif-thenの意思決定設計をセットで持つ。オーナーへの予算提案の下敷きにもなる想定。

---

## 0. まず結論から：もう「ゼロから」じゃない

コエテコで **iTeen武庫之荘校を検索したら、すでに口コミ175件・評価4.59点** が付いていた（[コエテコ掲載ページ](https://coeteco.jp/brand/iteen/schools/550027)）。「登録したい」というお話だったが、iTeen本部側の仕組みで**すでに掲載・口コミ収集は進んでいる**状態。

尼崎の競合と並べると：

| 教室 | 評価 | 口コミ数 |
|------|------|---------|
| **iTeen武庫之荘校（自社）** | **★4.59** | 175件 |
| プロクラ 開成園田教室 | ★4.5 | 737件 |
| デジタネ 松陰塾塚口校 | ★4.45 | 499件 |
| アーテック自考力キッズ | ★4.32 | 298件 |
| HALLO武庫之荘北校/阪急園田校 | ★4.31 | 319件 |
| Axisロボット JR塚口 | ★4.2 | 489件 |
| QUERO明光義塾武庫之荘 | ★4.0 | 1,463件 |

**評価点はすでに尼崎で実質トップ。** 足りないのは口コミの「数」だけ——プロクラの737件、QUEROの1,463件という母数に対して175件はまだ1/4〜1/8。つまり「尼崎No.1」は品質面ではもう手が届いていて、あとは物量戦。ここは吉田松陰の「志定まれば、気盛んなり」で、ゴールが遠いのではなく、あと一押しだと捉えていい。

**要確認**：月7,000円の話が「新規登録費」なのか「プレミアム掲載への切り替え費」なのか、iTeen本部or過去の契約書で実体を確認してほしい。この資料は後者（プレミアム化の意思決定）として設計しているが、前提が違えば数字を差し替える。

## 1. ゴール設計：「No.1」を定義する

「尼崎一番」「兵庫県一番」は曖昧なままだと戦略が立たない。コエテコ上で測れる軸は3つ：

| 軸 | 何で決まるか | 現状 |
|----|------|------|
| ① 評価点 | 口コミの平均星 | **すでに尼崎トップ級（4.59）** |
| ② 口コミ数（信頼の厚み） | 累計投稿数 | 175件、トップ集団（300〜1,500件）にまだ距離あり |
| ③ 検索露出 | 「プログラミング教室 尼崎」等での掲載順位・プレミアム枠の有無 | 未確認（無料枠なら埋もれる可能性） |

→ **尼崎No.1の定義はこうする**：「①評価点トップを維持しながら、②口コミ数で上位3教室（プロクラ737・デジタネ499・QUERO1,463）に並ぶ」。数だけ追って評価が落ちたら本末転倒なので、①を守りながら②を伸ばすのが勝ち筋。

### フェーズロードマップ

```
Phase 1（今すぐ〜3ヶ月・予算0円）
  口コミ最大化フェーズ。無料施策のみで175件→225件（+50件）を目指す

Phase 2（3〜6ヶ月・判断ポイント）
  実績データが貯まった時点でプレミアム化のROIを試算し、オーナーに提案
  目標: 口コミ300件、コエテコ経由の体験申込みを毎月計測できる状態

Phase 3（6ヶ月〜1年）
  尼崎No.1（評価トップ×口コミ上位）を確定させる
  地域No.1ブランド化（[[amagasaki-programming-school-competition]] 戦略3）と連動

Phase 4（1年〜）
  兵庫県No.1へ。武庫之荘という一店舗の口コミ数だけでは物理的に限界があるため、
  [[revenue-model-150man]] の柱②オンラインコース・柱①派遣モデルを使って
  「兵庫県内での受講者数・接点数」で勝負する設計に切り替える
```

## 2. 月7,000円 vs チラシ代——実は「二者択一」ではない

いま「チラシ代に使いたいから、コエテコにはまだお願いできない」という状態は、**両方を対立させてしまっている**。だが実際にはこの2つは順番でつながる：

```
チラシ・イベント予算
   ↓（人を呼ぶ）
体験レッスン・イベント参加
   ↓（体験後に依頼する）
コエテコへの口コミ投稿（無料枠のままでもできる）
   ↓（口コミが貯まる）
評価点・口コミ数が競合に近づく
   ↓（ここで初めて）
プレミアム化のROIが数字で語れる → オーナーに提案
```

つまり **今すぐやるべきはプレミアム化ではなく、「チラシ・イベント予算を口コミが増える動線に接続すること」**。コエテコ自身も体験後レビューでAmazonギフト券最大5,000円を配るキャンペーンをやっている（[GMOメディア公式](https://www.gmo.media/service/coeteco/)）。同じ発想で、自社の体験・イベント参加者に「口コミを書いてくれたら次回教材費500円引き」等の小さな特典を仕込めば、コスト0円に近い形で口コミ数を押し上げられる。

## 3. If-Then 意思決定設計

### A. プレミアム化するかどうか

```
IF   月間のコエテコ経由・体験申込みが3件/月以上に達する
THEN プレミアム化のROIは黒字化しやすい
     （コース単価17,710円は1名成約するだけで7,000円を優に回収できるため、
      "体験→成約が月1名でも出るなら黒字" が判断の下限ライン）

IF   プレミアム化して3ヶ月経っても新規体験問い合わせが目に見えて増えない
THEN 解約し、予算をチラシ・イベントに全額戻す
     （「お試しでダメなら撤退する」をあらかじめオーナーに約束しておくと、
      提案時のYESが出やすくなる）

IF   口コミ数が競合上位（300件目安）に近づく前に予算的余裕ができた
THEN 前倒しでプレミアム化してよい
     （口コミを"待つ"のではなく"増やす装置"として先行投資する価値がある）
```

### B. オーナーへの提案タイミング

```
IF   Phase 1（無料施策）を3ヶ月走らせて
     「体験申込み数」「うちコエテコ経由の比率」「口コミ増加数」の
     3つの実データが揃った
THEN そのデータを持ってオーナーに提案する
     ← これが「いつお願いできるか」の答え。
       感覚ではなく数字が出そろった瞬間が交渉のタイミング。

IF   オーナーが数字を見ても即答NOだった
THEN 「無料施策だけで口コミ+50件」の実績を追加で2〜3ヶ月積み増し、
     再提案する（一度断られても仕組みとして負けにしない）
```

### C. 尼崎No.1 → 兵庫県No.1 の切り替えタイミング

```
IF   尼崎エリアで評価点トップ×口コミ数が競合上位3校と並んだ
THEN 「兵庫県No.1」の定義を物理店舗の口コミ数から
     オンライン受講者数・派遣実績数にシフトする
     （尼崎市の対象年齢人口は約4万人、兵庫県は約49万人——
      [[amagasaki-programming-school-market-size]] 参照。
      武庫之荘一店舗の口コミだけで県全体を制するのは非効率）
```

## 6. 追記（2026-08-21）：「体験者に商品券」の仕組みは有料限定か

### 結論：ほぼ確実に有料プラン限定。ただしコエテコへの直接確認が最終確認

コエテコには「体験予約＋口コミ投稿でAmazonギフト券2,000円分、期間中に入会でさらに3,000円分（合計最大5,000円）」という常設寄りのキャンペーンがある（[コエテコ公式キャンペーンページ](https://coeteco.jp/campaigns/trial_class_entry)）。実際に多数の教室（ProgrameiQ、テラコヤエッジ、のぞみスクール等）が自社ブログでこれを宣伝しており、体験申込みを増やす実例として広く使われている。

このキャンペーンへの参加口（体験申込みの入口）は「**体験申し込みボタン**」だが、[shopowner-support.net の調査](https://www.shopowner-support.net/attracting_customers/class/programming-private-school/coeteco/)によると、**この「体験申し込みボタン設置」自体がプレミアム限定機能**として明記されている（フリープランには含まれない）。つまり：

```
フリープラン: 基本情報の掲載のみ。体験申込みボタンなし → ギフト券導線に乗せられない
プレミアム : 体験申込みボタンあり → ギフト券キャンペーンに参加できる
```

→ 彦阪さんが「そこを推したい」と感じたポイントは、**構造的にプレミアム化とセットでないと使えない可能性が高い**。これは月7,000円の価値を裏付ける具体的な機能なので、オーナー提案の「核」をこれに差し替えるべき。

### ただし2点、事前確認が必須

1. **ギフト券の原資は誰が払うか**：情報源によっては「教室側がキャンペーン費用を負担する」との記載がある。つまり月7,000円のサブスク費とは別に、体験1件ごとに2,000円、入会でさらに3,000円（合計最大5,000円/家庭）の変動費が乗る可能性がある。これを見落とすと「月7,000円で済む」という前提が崩れるので、**必ずコエテコの問い合わせ窓口で「ギフト券原資は教室負担かコエテコ負担か」を先に確認する**こと。
2. **iTeen本部が既にプレミアム契約済みかどうか**：4章の確認事項と同じ論点だが、この機能の有無で答え合わせができる。今のコエテコ掲載ページに「体験申し込みボタン」が表示されているか実際に見てみるのが一番早い確認方法。

### オーナー提案の核を更新する

第5章のテンプレートに、この具体策を差し込むとより説得力が上がる：

> コエテコには「体験予約で2,000円分、入会でさらに3,000円分のAmazonギフト券」という仕組みがあり、他の競合教室（プロクラ・デジタネ等）も軒並み活用しています。これはプレミアム化（月7,000円＋体験1件あたり最大5,000円のギフト原資）とセットでないと使えない機能です。粗利17,710円/月のコース1件成約でも十分回収できる計算なので、3ヶ月だけ試させてください。

数字（ギフト原資の負担元・実際の体験申込み単価）が確定次第、この資料を更新する。
