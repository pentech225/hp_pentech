# school/mukonoso — デザイン指針（脱・AIっぽさ）

## 背景
現行の `index.html` / `css/style.css` は、角丸15〜30px・パステルグラデーション背景・多重ドロップシャドウ・同じ形のカードを並べるBento UI的グリッドが多用されており、「いかにもAI生成っぽい」印象になっている。2026-09-26のユーザー指示に基づき、プロフェッショナルで実存感のあるサイトへ刷新する。今後この案件でHTML/CSSを書く・直す際は、必ず以下を確認すること。

## 4つの原則

### 1. 直線のエッジを増やす（角丸を使わない）
- `border-radius` は **0** とする（2026-10-28のユーザー指示「丸い囲いは全部無くして。AIぽくて嫌い」により、0〜4pxから0に変更。ピル型バッジ・丸ボタン・丸いドットも含めて全廃済み）。
- 現行に多い `border-radius: 8px / 10px / 15px / 20px / 30px` は廃止し、シャープでミニマルな印象にする。
- ボタンもカプセル型（`border-radius: 30px`）をやめ、角ばった/わずかに角丸（2〜4px）の矩形にする。

### 2. あえて枠線・背景色分けをなくし、余白（ホワイトスペース）で区切る
- カードごとに `background: #f9f9f9` や `#e0f2ff` のような色分け背景ブロックを多用しない。
- `border: 1px solid #eee` のような枠線も極力使わず、`padding` / `margin` の余白だけで情報を区切ることを優先する。
- **`border-left: 3px solid var(--accent)` のような「左側だけ色付きの縦棒（アクセントバー）」は禁止。** 強調ボックス・注意書き・引用のたびにこれを使うと、いかにも生成AIが作った量産テンプレのような、気持ち悪い印象になる（2026-09-27にユーザーから指摘・却下された）。強調したい場合は色付きの棒ではなく、太字・見出し・余白の大小だけで表現すること。

### 3. 実写・オリジナル画像を主役にする
- 絵文字アイコン（🎯🚀✨など）やパステル調のイラストに頼った装飾をやめる。
- 教室の実写真・生徒作品の実写・講師の実写・指導報告書の実例スクリーンショットなど、「実際に存在するサービス感」が伝わる画像を優先して使う。

### 4. ぷっくりした立体感（グラデーション・多重シャドウ）を排除
- `linear-gradient(135deg, #e0f2ff 0%, #f0f8ff 100%)` のようなパステルグラデーション背景ブロックは使わない。
- `box-shadow` は基本1段のみ、薄く（`rgba(0,0,0,0.06)` 程度）にとどめ、ホバーで浮き上がる多重シャドウ演出は最小限にする。
- 丸い3Dオブジェクト・流体（オーガニック）シェイプの装飾画像は使用しない。
- 例外：ヒーロー画像の上にテキストを重ねるための黒〜透明のグラデーション scrim（`.hero-overlay` 参照）は、視認性確保が目的の機能的な処理であり、ここで禁止しているパステル装飾グラデーションとは別物。削除しないこと。

### 5. 浮いたカードにしない（2026-10-28追加）
- 記事のタイトル・日付・カテゴリーを、影付きの白い箱に入れて背景から浮かせない（ユーザー指示「フローティングしなくていい。もっとシンプルに」）。
- 日付は灰色の小さな文字、カテゴリーは色付きの太字テキストのみ（背景色付きのバッジにしない）。タイトルは本文色の太字。
- 記事本文・ブログ一覧・ニュース一覧も、白箱＋影＋ホバーで浮き上がる演出をやめ、余白だけで区切る。共通の定義は `css/blog.css`（記事・ブログ一覧）と `css/style.css` の `.news-*`。

## 共通ナビゲーション（2026-10-28〜）
- PC（1024px以上）は左固定サイドバー、モバイル・タブレットは上部バーのハンバーガーで開くドロワー。
- 見た目は `css/layout.css`、開閉は `js/site-nav.js`。各ページは `<html class="has-sidebar">`、`<header class="site-topbar">`＋`<aside class="site-sidebar">`＋`<div class="sb-overlay">` のマークアップを持つ（`html/blog/ARTICLE_TEMPLATE.html` を参照）。
- メニュー項目を変えるときは全ページのサイドバーを揃えて直す。新しいページを作るときも同じマークアップと `layout.css`・`site-nav.js` の読み込みを入れる。
- `lp/index.html` はランディングページのためサイドバー対象外（角丸のみ撤去）。

## 実装時チェックリスト
- [ ] `border-radius` は 0〜4px か、意図があって使う場合のみそれ以上になっているか
- [ ] セクション/カードごとに背景色を変えていないか（白 or 透明 + 余白で構成できないか検討したか）
- [ ] 左側だけの色付きアクセントバー（`border-left: 3px solid ...`）を使っていないか
- [ ] 絵文字・装飾イラストではなく実写画像になっているか
- [ ] パステルグラデーション背景・多重シャドウを使っていないか
- [ ] 同じ形の丸角カードを並べるだけのBento UI的グリッドになっていないか（強弱・非対称なレイアウトを検討したか）

## 対象ファイル
- `school/mukonoso/index.html`
- `school/mukonoso/css/style.css`
- `school/mukonoso/html/` 配下の各ページ（faq.html, reserve.html, contact.html, values.html など）

## 出典
本指針は、ユーザーから提示された「AIっぽいデザインから脱却するための指摘」（2026-09-26の会話）に基づく。指摘内容：角丸の多用、Bento UI（丸角カードのグリッド）、パステルグラデーション/多重シャドウ（クレイモフィズム・グラスモフィズム）の多用、実写画像の不足。
