止まらなくなったとき どうして止まらないの？ 止まらないコマンドの作り方

こまったとき：コマンドブロックが止まらない！

コマンドブロックで動物を出しつづけていると、どんどん増えて、ブロックのところまで行けなくなることがあります。そのときは、上から順番にやってみましょう。

1. 全部のコマンドブロックを止める

キーボードの T を押してチャット欄を開き、これを打ちます。

/gamerule commandblocksenabled false

打ったしゅんかんに、すべてのコマンドブロックが止まります。画面が重くても、これだけは一番さいしょに打ちましょう。

2. 出しすぎた動物を消す

たとえば馬を出しすぎたときは、これを打ちます。

/kill @e[type=horse]
気をつけよう [type=horse] をつけわすれると、自分や、ほかの生き物までぜんぶ消えてしまいます。かならずつけましょう。ひつじなら sheep、ぶたなら pig に変えます。

3. コマンドブロックを直す

止まっているあいだに、コマンドブロックのところへ行き、つぎのどれかをします。

  • ブロックをこわす
  • 「反復」を「インパルス」（1回だけ動く）に変える
  • 「常にアクティブ」を「レッドストーンが必要」に変える

4. コマンドブロックを元にもどす

直しおわったら、これを打ちます。打たないと、コマンドブロックがずっと動かないままです。

/gamerule commandblocksenabled true
先生へ コマンドを使うには、ワールドの設定で「チート（コマンド）」をオンにしておきます。教育版はバージョンによってコマンドが通らないことがあるので、授業の前に一度打ってたしかめてください。

どうして止まらないの？

たとえば、こんなコマンドを「反復」のコマンドブロックに入れたとします。

/execute at @p run summon horse ^ ^ ^3
ことばいみ
execute at @p一番近くにいるプレイヤーの場所で
summon horse馬を出す
^ ^ ^3自分の目の前、3マス先に
「反復」のブロック1秒に20回くりかえす

つまり、自分がどこへ歩いても、目の前に1秒で20頭の馬が出つづけます。コマンドブロックに近づこうとするほど、目の前が馬でうまってしまいます。だから、さいしょに「1. 全部のコマンドブロックを止める」をするのが近道です。

止まらないコマンドの作り方

止まらなくなったら、それは失敗ではなく直すチャンスです。「どうして止まらないの？」を考えて直すことを、プログラミングではデバッグといいます。

ボタンを押したときだけ出す

  1. コマンドブロックを「インパルス」にする
  2. 「レッドストーンが必要」にする
  3. ブロックの横にボタンをつける

ボタンを1回押すと、1頭だけ出ます。

出す場所を決める

@p（自分の場所）のかわりに、場所を数字（ざひょう）で決めると、自分についてきません。

/summon horse 100 64 100

数字は、画面に出ている「位置」を見て、自分のワールドに合わせて変えましょう。

回数を決めてくりかえす（Code Builder）

Code Builder（C キー）では、「ずっと」ではなく「10回くりかえす」を使うと、10回で止まります。数を変えるとどうなるか、予想してからためしてみましょう。
