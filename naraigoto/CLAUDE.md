# naraigoto — 尼崎の習い事ガイド

尼崎市の子どもの習い事を、条件から探して比べられるページ。公開後のURLは `https://www.pentech.info/naraigoto/`。戦略とあまっぷへの掲載提案は `C:\company\vision\op\school\261028_尼崎習い事ガイド_戦略とあまっぷ掲載提案.md`。

## ファイル
- `index.html` — ページ本体。「並び順の決め方」の文章は `js/app.js` の `score()` と必ず一致させる
- `js/app.js` — 条件の入力・点数の計算・リスト・地図（Leaflet＋OpenStreetMap）・比較表
- `css/style.css` — `school/mukonoso/CLAUDE.md` のデザイン指針に従う（角丸0、色付きの箱・左の縦棒・グラデーションなし）
- `data/schools.json` — 教室データの正本。手で直してよい
- `tools/geocode.py` — 座標がない教室だけ、国土地理院の住所検索で座標を付ける（`python -I naraigoto/tools/geocode.py`）
- `tools/seed_261028.py` — 初期データを作った一回限りのスクリプト。再実行すると取材の記録を上書きするので実行しない

## 公平さのルール（いちばん大事。本人の言葉「公平性は、必ず」）
- 対象は習い事全体。プログラミングだけに偏らせない（競合は習い事全体、2026-10-28本人決定）。
- 取材の依頼では「あまっぷの取材です」と「私自身プログラミング教室をしています」の両方を最初に伝える。
- 運営者が教室を経営していることを隠さない。自教室には `"own": true` を付け、「運営者の教室」と表示する。
- 点数の計算で、自教室だけを加点しない。
- ほかの教室を悪く書かない。事実と出典だけを書く。
- 口コミサイトの文章は丸写ししない。評価の数値と件数、リンクだけを載せる。

## データの書き方（schools.json の1件）
- `id`: ジャンルの頭文字＋連番（p=プログラミング・ロボット, s=スイミング。新しいジャンルは新しい頭文字）
- `category`: `js/app.js` の `CAT_GOALS` にあるジャンル名
- `area`: 武庫之荘／塚口／園田／立花／JR尼崎／阪神尼崎／出屋敷・南部
- `ageMin` / `ageMax`: 3=年少 4=年中 5=年長 6=小1 … 12=中1 15=高1 18=大人以上
- `coeteco`: 評価 `rating`・件数 `reviews`・`scope`（ブランド全体か教室単位か）・確認日 `checked`
- `sources`: 出典は必ず1つ以上。`label`・`url`・`checked`（確認日）
- `price` / `trial`: 確認できたら文字列で入れる。わからなければ書かない（「未確認」と表示される）
- `interview`: 取材の記録。下の項目

## ランキングの指標（2026-10-28、取材前に決定）
本人の方針：「ランクをつけて一番を決める。客観的な数値で。コエテコと同じことをしても意味がない」。
コエテコとの違いは、①ブランド全体でなく教室ごとの数字、②口コミの点数でなく取材で聞いた数字、③ジャンルをまたいで比べる（1時間あたりの月謝）こと。

`facts` に入れる値（すべて数値。教室が「公開してよい」と言ったものだけ）：
- `date`: 聞いた日（YYYY-MM-DD）
- `students`: 生徒数
- `teachers`: 講師数
- `kidsPerTeacher`: 1回の授業で講師1人が見る子どもの数
- `avgYears`: 生徒の平均の在籍年数（教室の申告）
- `foundedYear`: 開校年（西暦）
- `monthlyFee`: 小学生の標準コースの月謝（税込・円）
- `minutesPerMonth`: その月謝での月の授業時間（分）。1時間あたりの月謝の計算に使う

ルール：
- 指標は `js/app.js` の `METRICS` と `index.html` の「No.1の決め方」で同じにする。**結果を見てから指標を足したり外したりしない。** 変えるときは日付と理由を「No.1の決め方」に書く。
- その範囲で数字がそろった教室が3つ未満なら、No.1を出さない（`RANK_MIN`）。
- 自教室の数字は、自分以外の人が聞き取る。

## 公開しないデータの置き場所
`schools.json` は公開サイトに置かれるので、**中に書いたものはすべて誰でも読める。** 公開に同意のない数字（シェア計算用の在籍数など）や取材メモ、知り合いの名前は、ここに書かない。`C:\company\edu\naraigoto\` に置く（巡回リストも同じフォルダ）。

## 学校（data/gakko.json、2026-10-28〜）
習い事と同じページで扱う（本人決定「同じガイドに入れる」）。条件の「通っている学校」をえらぶと、学校の位置から距離を計算する。
- 対象：尼崎市立の小学校41校・中学校18校（出典は尼崎市の令和8年4月1日現在の一覧PDF）。私立・国立、幼稚園・保育園は集めてから足す。
- `id`: e=小学校, j=中学校, 以降は追加時に決める（p は習い事で使用済み）。`short` は「武庫東」のような短い名前。
- 取材の名乗り方は習い事と同じ（「あまっぷの取材です」＋「私自身プログラミング教室をしています」）。
- 載せるのは**学校のいいところ・行事・放課後の過ごし方**など、学校が公開してよいと言ったものだけ。
- **先生が抱えている課題は、`gakko.json` に書かない。** 公開すると先生や学校が特定され、次の取材を受けてもらえなくなる。課題は `C:\company\edu\naraigoto\` の取材メモに残し、記事にするときは学校名を出さず、複数校の声をまとめた形にする。
- 校長名などの個人名は載せない。

## 取材シートの項目（interview）
全教室で同じ項目にする。
- `status`: 未取材／依頼中／取材済み／取材お断り
- `date`: 取材日（YYYY-MM-DD）
- `summary`: 一行のまとめ（比較表に出る）
- `teacher`: 先生の関わり方（教える／見守る／待つの割合、声のかけ方）
- `kids`: 子どもの表情・集中の様子
- `room`: 1回の人数、先生1人あたりの人数、教室の広さ
- `price`: 月謝・入会金・教材費・その他の費用
- `makeup`: 振替のしやすさ
- `article`: 取材記事のURL（自サイト・あまっぷ）
- `video`: YouTube動画のURL（撮影の許可がとれた場合）

数値は `interview` ではなく `facts` に入れる（上の「ランキングの指標」）。公開に同意のない値は `schools.json` に入れない。
